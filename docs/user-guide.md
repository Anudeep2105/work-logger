# User guide

## Sign in

Open the installed client or organization HTTPS URL. Sign in with your username and password. Change temporary passwords when prompted; sign out on shared devices.

## Employee

- Review own tasks, due dates, status, and context; mark tasks done when accurate.
- Request a correction to a task or feedback and follow Pending/Accepted/Declined status and resolution note.
- View only manager feedback explicitly shared with you. HR review appears when available.

## Manager

- Create tasks for active employees assigned as direct reports; the server enforces this boundary.
- Correct task title, context, due date, status, quality note, or contributors.
- Create a 1–5 rating with review period, title, written examples, and optional related task.
- Keep feedback as a draft or explicitly share it with the employee and HR.
- Correct your feedback. If shared, the existing HR review is cleared for reevaluation.
- Resolve direct-report correction requests with a note.

## HR reviewer

Review only shared manager feedback. Add an independent 1–5 grade, written assessment, and Reviewed / Follow-up required disposition. HR cannot edit task or manager-authored feedback records.

## Rating scale and interpretation

1 Unsatisfactory; 2 Needs improvement; 3 Meets expectations; 4 Strong; 5 Exceptional. Ratings require written context. They are human judgments, not automated outcomes. Consider role expectations, quality, collaboration, workload, dependencies, changed priorities, and employee input.
