## Product boundary

Worklog records tasks, manager feedback, employee correction requests, and independent HR review. Ratings and grades are human-authored decision-support inputs. They are not an automated appraisal or a sole measure of employee performance. Use role context, quality, dependencies, workload, changed priorities, and employee explanations when interpreting records.
